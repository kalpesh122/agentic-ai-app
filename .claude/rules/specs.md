# Spec and ADR rules

- Acceptance criteria are testable sentences ("GET /todos/:id returns 404 for an unknown id"), never adjectives.
- Open questions must be empty before implementation starts.
- `tasks.md` is the progress log: tick items with a one-line proof (test name or command output).
- ADRs are decisions, not designs: one screen, alternatives listed, consequences honest.
